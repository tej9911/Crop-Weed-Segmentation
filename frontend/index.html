Architecture & Technical Context

Underlying specifications of the MT-AHNet model structure.

The MT-AHNet model uses multi-scale features combined with attention mechanics to map spatial vegetation masks.

Input Layer 128 × 128 × 3 RGB Image
Multi-scale Convolutions Parallel 1×1, 3×3, 5×5 kernels
CBAM Attention Block Channel + Spatial Weights
Residual Downsampling Deep Feature Learning Stages
Softmax Classifier 4-Class Probabilities output

The Convolutional Block Attention Module (CBAM) sequentially applies channel and spatial attention:

  • Channel Attention: Focuses on 'what' features are important (e.g. green vegetation vs brown soil) by pooling spatial dimensions and applying shared MLPs.
  • Spatial Attention: Focuses on 'where' the targets are (localizing weed clusters) by average-pooling and max-pooling along channels, then convolving with a 7x7 filter.

This mechanism prevents the network from losing fine weed structures in soil-heavy regions.

Training and architecture configurations documented in the research paper:

Optimizer: Adam (1e-4)
Loss: Cross Entropy
Model Size: 12.4 MB
Parameters: ~197K

Trained on high-definition multispectral agronomy datasets including varying lighting and row configurations.
