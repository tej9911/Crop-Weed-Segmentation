Precision agriculture, patch by patch

MT-AHNet combines multi-scale convolutions with CBAM channel and spatial attention to classify image patches from soybean fields as soybean, grass weed, broadleaf weed or bare soil. Upload a field patch to see the prediction, the class probabilities and a colour map of where the vegetation is.

How the model works

The network that runs behind the prediction.

Input128 × 128 × 3 RGB, scaled to [0, 1]
▼
Multi-scale blockParallel 1×1, 3×3, 5×5 convolutions
▼
3 × residual CBAM stage64 → 128 → 256 filters, stride 2
▼
Global average pool+ dropout 0.3
▼
Softmax4 class probabilities

The Convolutional Block Attention Module (Woo et al., 2018) re-weights features in two steps:

  • Channel attention decides what matters: average- and max-pooled descriptors pass through a shared MLP to weight each feature map.
  • Spatial attention decides where to look: channel-wise mean and max maps pass through a 7×7 convolution to weight each location.

This helps the network focus on thin leaves and stems against soil-dominated backgrounds.
